# ECS Rules

このドキュメントでは、本プロジェクトにおけるECSのルール、仕様、思想について定義する

---

# 仕様
アーキタイプチャンクのECSを作成している

* Entity
- uint64_t の識別子 前半32bitが世代,後半32bitがインデックスとなっている

* Component
- PODを厳守しているためトリビアルコピーかつ標準レイアウト以外はstatic_assertではじいている
- 保存にはコンポーネント名を使用
- ランタイム中はstaticでtemplateごとにIDを発行している
- エンティティに同じコンポーネントを複数個つけるのはできない

* System
- システムごとに.Beforeと.Afterをつけて順序を処理している
- システムにはフェーズを指定してそのフェーズ内でのソートになる
- クエリはコンポーネントの組み合わせのシグネチャを記憶している
- 依存を示すために const で示したコンポーネントは読む、ついていないのは書きこむを指定している
- Job化するために依存でトポロジカルソートをしてDAGを組んでいる

* Chunk
- サイズは64kb
- ブロックで確保してそこからメモリを割り当ててもらう

* Archetype
- コンポーネントをBitsetで管理している
- チャンクのポインタ配列を持っている
- 内部のエンティティが0になっても1チャンクのみは残すようにしている

* Resource
- 型ごとにランタイムIDを発行してシステム内でアクセスできるようにしている。
- 特定のエンティティが持たないものや一時的なバッファなどのために活用
